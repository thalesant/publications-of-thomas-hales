# Changes from the 2016 arXiv version to manuscript v005

**Baseline:** *Packings of Regular Pentagons in the Plane*, arXiv:1602.07220v2, 13 September 2016, **60 pages**, from `arXiv-1602.07220v2.tar.gz`. **Revised version:** `paper/pentagon_v005.tex` and its **73-page PDF** in `pentagon_release_v003.zip`. **Referee report:** `report_Y_on_v2.pdf` from `tex.zip`; the manuscript in that ZIP is **not** the baseline.

Page references below are printed PDF pages, not source-line numbers. “Referee” identifies an implemented request from the report. Spelling, grammar, capitalization, and minor cross-reference corrections have been made throughout and are not itemized. Unchanged results are omitted. The table is ordered by the original manuscript, with associated appendix changes grouped with their statements.

## Referee follow-up

The substantive requests have identifiable responses above. Two points should be distinguished from an unqualified claim that every request was implemented literally:

| Referee request | Status in the revised delivery |
|---|---|
| Report p. 2: print a concrete repository/file/function locator at each computer-assisted statement, rather than an unexplained calculation footnote. | **Alternative implementation.** The companion index provides the mapping by printed statement number and source label. The PDF still does not print full paths at each statement. Explain this alternative explicitly in the response to the referee. |
| Report p. 3: “P. 31. Proof of Lemma 72. Lemma 26 is used here but not mentioned.” | **Ambiguous locator.** Original Lemma 72 is on p. 30; p. 31 contains the proof of Theorem 63 and Lemma 73. Both corresponding passages now cite Lemma 4.2 (original Lemma 26), on revised p. 40. If the referee literally intended Lemma 72, its counterpart, Lemma 8.10 on p. 39, still has no explicit citation to Lemma 4.2. |

The requested proof roadmap was placed at the end of the **Introduction**, not at the end of §2. No other unaddressed non-typographical request was identified in this comparison. This table records textual and organizational changes, not a new mathematical audit. No manuscript or code was altered to prepare it.
