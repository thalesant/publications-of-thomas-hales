# Release provenance

This directory records integration and preparation, not successful execution of a
new full mathematical run. `file-changes.json` identifies unchanged, modified,
added, and removed paths relative to the preceding computational distribution.
`mathematical-source-equivalence.json` verifies preservation of the numerical
module bodies and the previously executed additional calculations/control.
`input-identities.json` identifies the input archives and approved manuscript.
`PREPARATION.md` distinguishes actual preparation tests from future local run records.

Old copies of manuscripts, obsolete launchers, ad-hoc patch archives, and private
conversation files are not part of this release. Keep Git history or the prior
release archive for historical reconstruction; the working tree has one current
paper, one registry, one driver, and one confirmation scope.
