# Preparation of the consolidated distribution

This record describes the checks performed while preparing code v004 with the
approved manuscript v007. It is separate from the source-specific mathematical
execution record generated by `confirm.py` after a user's run.

## Performed here

- 126 Python controller, integration, navigation, and integrity tests passed.
  Child calculation processes and completion fixtures in those tests are explicitly
  synthetic. Tests include longest-first order, a live five-process fixture,
  CPU/RAM limits, all four prerequisite gates, status/import failure cases,
  confirmation after relocation, and preservation of contributing log folders.
- 56 exact symbolic/rational identity and numerical-margin checks passed with the
  optional SymPy checker. They do not replace the Wolfram or interval searches.
- The approved manuscript, PDF, driver, compiled bibliography, bibliography source,
  and 168-label map are byte-identical to the v007 input package.
- The numerical bodies of the production modules, integrated additional estimates,
  and geometric control match the previously executed sources. Loader, dispatch,
  runner, registry, source-identity metadata, and documentation were integrated;
  no mathematical cutoff or subdivision rule changed.
- The current code commentary and figure gallery were compiled; selected rendered
  pages were visually inspected. Local documentation links and every fixed-file
  digest were checked. The final archive was also extracted to a differently
  named directory containing spaces and the checks repeated there.

## Execution boundary

OCaml/opam and a Wolfram kernel were not installed in this preparation environment.
The newly assembled OCaml loading/dispatch path and the Wolfram report export have
not been executed here. In particular, synthetic controller results do not claim
that the new 77-stage required run has completed. The sources have successful
prior execution evidence; this fresh distribution deliberately supplies no old
run directory or checkpoint as a current-release pass.

The 77 required stages and all 161 Wolfram checks are verified by the ordinary
run and confirmation commands in the root README. The generated confirmation
then records the actual source/environment identities and log digests. It can
be included with its contributing logs in a verified distribution archive.

## Change preservation

`file-changes.json` compares root-relative files with code v003. It records
unchanged bytes as well as additions, replacements, and removals. Removed items
are old manuscript copies, historical patch/audit folders, stale generated
outputs, and duplicated earlier execution logs. The original external archives
are identified, not embedded. Old archives can remain in a separate personal
backup; they are not runtime dependencies of this release.
